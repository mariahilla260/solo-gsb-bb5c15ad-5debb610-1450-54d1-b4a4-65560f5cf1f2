      📦 方案规则版本

      同一方案的规则支持草稿 / 发布 / 停用，判定只读取当前生效版本

      为方案创建规则版本时会克隆当前生效版本（首次则克隆全局限定规则图）作为草稿； 草稿可随意调整规则集合与严重级别依据并预览，发布后推演 / 导出等判定接口只读取该版本快照， 原生效版本自动转为「已替代」；停用后该版本不再参与判定，方案回落至全局限定规则图。

      相容性规则图

      节点 = 试剂类别；边 = 相容性禁忌。边的颜色表示严重级别，虚线表示有向规则。点击节点或边可查看判定依据；拖拽节点可调整布局，滚轮缩放，空白处拖动平移。

        追加自定义规则
